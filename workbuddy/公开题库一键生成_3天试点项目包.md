# 公开题库一键生成 · 3 天试点项目包

> 主缺口 A（已重锁范围）：把"公开考试 → 一键可刷题库"闭环铺开到多品类
> 覆盖：辅警 / 消防 / 广东省考 / 深圳事业编 / 海南省考
> 双价值：自用备考 + 诚实分发（省考/事业编被巨头垄断，定位"公开整理版"，不碰"独家/押题"话术）

## 目标
用 WorkBuddy 把"公开考试 → 一键可刷题库"做成可复用的人机混编流水线，先打通一个品类验证闭环，再横向铺开。

## 输入 / 数据源
- 现有「每日辅警+消防员招录汇总」自动化（每日 09:00）—— **需扩展** 广东省考 / 深圳事业编 / 海南省考 公告源
- 公开题源：各省考 / 事业编大纲与机构流转题（WebFetch 抓取，标 `needs_verification` 后方可进客户稿）
- `rcj-exam-builder` skill（生成静态刷题站卡组）
- 诚实度校验：比对各品类题重合度，避免"套壳伪装"

## 每日任务

### Day 1 — 扩源 + 出首个小样
- **动作**
  1. 扩展「每日招录汇总」自动化，新增 广东省考 / 深圳事业编 / 海南省考 公告源（保留原辅警/消防）
  2. 挑 1 个公开题源最丰富的品类（建议海南省考 或 广东省考）跑 `rcj-exam-builder` 出小样题库
- **依赖能力**：`automation_update`（扩展公告源）、`rcj-exam-builder`、WebFetch
- **验收**：① 自动化新源次日 09:00 能看到新公告；② 生成可刷 Preview + 来源标注清晰

### Day 2 — 打通映射 + 诚实度校验
- **动作**
  1. 建立 `考试品类 → 科目 → 题库` 映射表（见 `品类-科目-题库映射表.md`）
  2. 联调"品类 → 科目 → 题库"一键生成
  3. 跑诚实度校验脚本，输出重合度报告
- **依赖能力**：`rcj-exam-builder`、比对脚本
- **验收**：给一个品类能一键出题库；重合度报告产出

### Day 3 — 上线 / 自用
- **动作**
  1. 上线到刷题站子路径（如 `/gd/` `/hainan/` `/szsy/`）
  2. 自用则导 Anki / RemNote
  3. 诚实标"公开整理版"，不碰"独家/押题"
- **依赖能力**：git push（Cloudflare 自动上线）、Anki / RemNote 导出
- **验收**：链接可访问 或 本地卡组可用

## 交付物
- `公开题库一键生成_3天试点项目包.md`（本文件）
- `品类-科目-题库映射表.md`（模板，Day 2 填充）
- Day 1 末：扩展后的自动化 + 首个小样题库
- Day 2 末：映射表填充 + 重合度报告
- Day 3 末：上线链接 或 本地卡组
